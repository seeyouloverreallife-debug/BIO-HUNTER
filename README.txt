Bio-Hunter v17.5 — PWA (ติดตั้งบนมือถือ/ไอแพดได้)
================================================
1) อัปโหลดทั้งโฟลเดอร์นี้ขึ้นเว็บโฮสต์ที่เป็น HTTPS (เช่น Netlify Drop, Cloudflare Pages, GitHub Pages)
   - ต้องอัปโหลดทุกไฟล์ในโฟลเดอร์ (index.html, manifest.webmanifest, sw.js, icons/) ไม่ใช่แค่ index.html ไฟล์เดียว
2) เปิดลิงก์บนเครื่อง:
   - iPhone/iPad: ใช้ Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
   - Android: Chrome → เมนู ⋮ → "ติดตั้งแอป" / "เพิ่มลงในหน้าจอหลัก"
3) หลังติดตั้งครั้งแรก เล่นออฟไลน์ได้
หมายเหตุ: ภาพสัตว์ฝังอยู่ใน index.html แล้ว (ไม่ต้องมีโฟลเดอร์ art/)
เซฟเดิมจาก v16.x/v17.0 ใช้ต่อได้ (คีย์เซฟเดิม bio-hunter-warden-v3 ไม่เปลี่ยน)

v17.5 — โครงราชินีรังแยกชิ้น (อัปเดตจาก v17.4)
------------------------------------------
* ราชินีรังประกอบจาก 11 ชิ้น: ท้อง (ส่ายเบา ๆ) / อก / หัว / ปีก 2 ข้าง (กระพือ) / ขา 6 ข้าง (ขยับตามการเดิน แบบสลับสามขา)
* ภาพใหม่จาก ChatGPT แทนชิ้นลำตัวเดิมที่ขาติดกับตัว (ภาพ r33 ที่ซ้ำซ้อนเก็บไว้ใน art-incoming)

v17.4 — ไอคอนสถานะผิดปกติ (อัปเดตจาก v17.3)
--------------------------------------------
* ไอคอน 8 อัน: พันธนาการ / ดูดพลัง / เปราะ / เลือดไหล / ไฟลวก / ชา / ตาพร่า / ติดเชื้อ
* แสดงนำหน้าข้อความสถานะใน HUD ซ้ายบนตอนสู้ (ตัดบรรทัดอัตโนมัติเมื่อมีหลายสถานะ) และในตารางสถานะหน้า "วิธีเล่น"
* ภาพสถานะที่ยังไม่โหลดจะแสดงเป็นข้อความเหมือนเดิม

v17.3 — ภาพลูกน้องแมลง (อัปเดตจาก v17.2)
------------------------------------------
* ฝูงแมลงลูกน้องของราชินีรังใช้ภาพจริง 2 เฟรม (ปีกพับ/ปีกกาง) สลับกันเป็นจังหวะกระพือ แทนวงรีสีเหลืองเดิม
  มีกะพริบขาวตอนโดนตี · ขนาดฮิตบ็อกซ์และการเล่นเหมือนเดิม

v17.2 — ภาพ Hivemother Queen ครบชุด (อัปเดตจาก v17.1)
-----------------------------------------------------
* ราชินีรังมีภาพจริงในสนามรบ: ตัวมองจากบนแยกชิ้น (ลำตัว/หัว/ปีก 2 ข้างกระพือ) แทนวงรีสีเหลืองเดิม

* พอร์เทรตราชินีรัง (กระดานภารกิจ/สมุดบันทึก/หน้าตัดสินใจ/กลุ่มวัสดุในกระเป๋า)

* ชุดเกราะ "เกราะไคตินราชินี" ครบ 4 ชิ้น (หมวก/อก/แขน/ขา)

v17.1 — ปรับ UX/UI (อัปเดตจาก v17.0)
-------------------------------------
จอมือถือแนวนอน (ปัญหาหลักที่แก้)
* ตัวอักษร HUD บน canvas ถูกขยายตามจอเล็กอัตโนมัติ (สูงสุด ×1.4) — เดิมจอสูง ~360px เหลือตัวอักษรจริง ~7px
  จัด HUD เป็น 3 ก้อน ซ้าย (ผู้เล่น) / กลาง (มอนสเตอร์) / ขวา (Trauma) ไม่ทับกัน · จอใหญ่/เดสก์ท็อปหน้าตาเดิม
* ข้อความแนะนำล่างจอและข้อความภาคสนามตัดบรรทัดอัตโนมัติ (เดิมล้นขอบจอ)
* หน้าหมู่บ้าน: เหรียญกลับมาแสดงบนจอกว้าง (เดิมหลุดขอบจอ) · แถว "วัสดุ/ป่า/คอก" ไม่ทับกันแล้ว · มีพื้นหลังโปร่งกันตัวหนังสือทับตึก
* ภาคสนาม: แผนที่ย่อไม่ถูกปุ่มสัมผัสบัง (ย้ายมาใต้กล่องซ้ายบน) · แถวข้อมูลไม่ทับกัน
* จอสัมผัส: ปุ่มในแผงเมนูมีขนาดกดง่ายขึ้น (สูง ≥ 38–42px) · ข้อความ "F — คุยกับ..." เปลี่ยนเป็น "แตะ ตรวจ/เก็บ — ..." บนมือถือ

แผงเมนู (กระดาน/กระเป๋า/ทักษะ/ตั้งค่า ฯลฯ)
* แถบหัวกะทัดรัดติดขอบบนตอนเลื่อน: [← กลับหมู่บ้าน · ชื่อหน้า · เหรียญ · กระเป๋า] — ไม่ต้องเลื่อนกลับขึ้นไปกดกลับ
  (เดิมส่วนหัวกินพื้นที่เกือบครึ่งจอมือถือแนวนอน)
* ลบหัวข้อซ้ำซ้อนในหน้ากระดานภารกิจ · ปรับระยะห่างสำหรับจอเตี้ย

จอแนวตั้ง
* หน้า "หมุนอุปกรณ์เป็นแนวนอน" ใหม่ อ่านชัดมีไอคอนหมุน (เดิมซ้อนกันสองชั้นและตัวอักษรอ่านไม่ออก) พร้อมปุ่ม "เล่นต่อแบบแนวตั้ง" สำหรับคนที่ล็อกการหมุนจอ
